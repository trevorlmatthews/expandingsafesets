Expanding Safe Sets with Learning-Based Barrier Functions and Reachability

Trevor Matthews, Mahesh Kumar, Azra Begzadić, Sander Tonkens, Zhirui Dai, Nikolay Atanasov, Jorge Cortés, Sylvia Herbert
Paper Github Poster Video

Overview of our data-driven framework for safe navigation. Given measurments from on-board sensors, an SDF is computed via Gaussian Processes (GP). To ensure continous differentiability, the SDF is smoothed around points of discontinuity. The smooth SDF is then used as a canidate CBF, acting as an efficient initialization for a reachability analysis to generate a valid CBVF. This CBVF then enforces the safety constraint for the next control input.

Abstract

This paper presents a learning-based framework for synthesizing and continuously adapting a robust control barrier value function for safe robot navigation in unknown environments. The approach first learns a smooth and robust signed distance function, which naturally encodes the distance to obstacles, from noisy LiDAR data using Gaussian process regression and a Bayesian Hilbert Map in real-time. This learned pessimistic estimate of the signed distance function serves as a candidate control barrier function, which is then formally refined using Hamilton-Jacobi reachability analysis to generate a valid control barrier value function that accounts for the system dynamics and control input constraints. This entire process operates in real-time, allowing the safe set to expand as the system explores its surroundings while maintaining probabilistic safety guarantees. The effectiveness of this approach is demonstrated through both simulation and hardware experiments on a Clearpath Jackal robot navigating cluttered environments.

Learning smooth SDF via GP regression

We use Gaussian Process (GP) regression to learn a smooth surrogate function \(s\) of the underlying SDF \( d\), modeling \(s\) as \(s(\cdot) \sim \mathcal{GP}(0,k_{s}(\cdot,\cdot))\), where \(k_{s}(\cdot,\cdot)\) is a kernel function. The GP is trained on a dataset of \(N\) noisy SDF measurements \(\mathcal{D} = \{(x^{i}, y^{i})\}_{i=1}^{N_{k}}\), for state \(x_{i}^{(k)}\) and measurment \(y_{i}^{(k)} = s(x_{i}^{(k)}) + \epsilon_{i}^{(k)}\) with \(\epsilon_{i}^{(k)} \sim \mathcal{N}(0, \sigma_{on}^{2})\). Assuming the function \(s\) lies within a Reproducing Kerneler Hilbert Space (RKHS) associated with kernel \(k_{s}(\cdot,\cdot)\), we establish the following error bound for the GP regression.

\begin{equation} \Pr\!\left\{ \, \big| \mu_{s}(x) - s(x) \big| \leq \beta \sigma_{s}(x), \; \forall x \in \mathcal{X} \right\} \geq 1 - \delta. \end{equation}


We consider a monotonically decreasing nonlinear transformation \(r: \mathbb{R} \rightarrow \mathbb{R}\) to obtain the unsigned distance function \(\tilde s_{u}: \mathbb{R} \rightarrow \mathbb{R}\) from the posterior mean of the surrogate function: \(\tilde s_{u}(x) = r(s(x)) \). By considering only monotonically decreasing transformations, we can propegate the above probablistic error bound to the unsigned distance function. Given a smooth surrogate function \(s\) (with appropriately smooth kernel \(k_{s}()\)), and r being a composition of smooth nonlinear transformations, we ensure that the resulting distance function is smooth. As a result, applying the transformation \(r(\cdot)\) reverses the signs of the probablistic bounds, yielding:

\begin{equation} \label{eq:inv} r(\mu_{s}(x) + \beta\sigma_{s}(x)) \le r(s(x)) \le r(\mu_{s}(x) - \beta\sigma_{s}(x)) \end{equation}

with probability of at least \(1 - \delta\).
To obtain a smooth SDF estimate \( \tilde{d}(x) \), we apply a Bayesian Hilbert Map (BHM) \(b(x)\) to \(\tilde s(x)\), assigning the sign at each state:

\begin{equation} \tilde{d}(x) = b(x) \tilde s(x). \end{equation}


CBVF Construction

Since direct use of the posterior mean may overestimate safety in uncertain regions, we consider a pessimistic estimate of the SDF \( \underline{d}\). The resulting superlevel set is an inner approximation of the true safe set \(\mathcal{C} \).

The resulting GP-SDF can now be used as the constraint function in an HJR formulation to construct and refine a valid CBF with respect to general control-affine dynamics with bounded control inputs. The initial approximate CBF is set as \(h_0(x) = \underline{d}_{0}(x)\) and the constraint function is set as \(\mathcal{l}_{0}(x) = \underline{d}_{0}(x)\). The following discreteized HJR-VI is solved via dynamic programming until convergence to a valid CBF.

\begin{equation} h_0^{(k+1)}(x) \leftarrow \min \left\{\ell(x), h_0^{(k)}(x)+\Delta^{(k)} L_f^* h_0^{(k)}(x)\right\}, \end{equation}


In practice, refineCBF does not execute at every time step \( t_{k} \), but rather proceeds in iterations, indexed by \( j \). As the environment is updated with each subsequent iteration, the constraint function updates to \(\mathcal{l}_{j}(x) = \underline{d}_{j}(x)\) and the CBF is initialized as \(h_j^{0}(x) = h_{j-1}^{*}(x)\). These processes are run in parallel at different update frequencies, with the SDF updating at a higher frequency than the CBF refinement.

Safe Control Synthesis

Assuming an iteration j exists for which we obtain a converged value function \(h_{j}^{*}\), any future CBVF \(h_{l}\) with \(l \ge j\) characterizes control invaraince. The resulting valid CBVF can be integrated into a real-time safety filter which minimally modified a desired nominal control law \(u_{\text{nom}}(x)\) via the quadratic program (QP):

\begin{gathered} \begin{aligned} u^*(x) &= \arg \min_{u \in \mathbb{R}^p} \left\|u_{\text{nom}}(x)-u\right\|_2^2 \\[2pt] \text{s.t.}& \nabla_x^{\top} h_l(x)\big(f(x)+g(x)u\big) + \alpha(h_l(x)) \ge 0 , \end{aligned} \end{gathered}


The existance of a forward invariant solution to this QP is guaranteed for all states \(x \in {x \vert h_{l}(x) \ge 0}\) wherever the gradient \(\nabla_x^{T} h_{l}(x)\) is defined.

Simulation Experiments

We evaluated our method in a simulated warehouse environment against two baselines: an oracle with a fully converged CBVF and a safety filter using only the learned GP-SDF as a CBF. The GP-SDF controller fails immediately due to overestimation of the safe set. Our method successfully navigates the environment while continuously expanding the safe set as new measurements are received. The trajectory taken converges to that of the oracle as the safe set expands over time, converging to the true safe set defined by the oracle.

Warehouse Navigation

Varying the measurment noise and effective measurment range, we performed an ablation study to evaluate the impact of these parameters on the performance of our safe controller. We demonstate our framework is robust to high-noise measurments, taking a longer trajectory than nominal but maintaining safety throughout. However, reducing the effective measurment range significantly degrades performance, as the reduced information available to the GP-SDF leads to conservative safe set estimates and an inability to reach the goals.
